# Features for future paywall restoration

Paywalls are currently disabled. This list records future entitlement requirements; it does not activate billing or access restrictions.

| Feature | Future paywall trigger | Current availability |
|---|---|---|
| Include non-signed/unsigned players in a league player pool | Commissioner enables unsigned-player inclusion | Available with paywalls disabled |

The future gate applies to enabling this option. Existing league/player ownership migration and subscription-expiration behavior require a defined policy before paywalls are restored.
